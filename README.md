# NYPD-Arrests-2025-January-June-

This Project uses data taken from NYC Open Data which can be found here:
https://data.cityofnewyork.us/Public-Safety/NYPD-Arrests-Data-Historic-/8h9b-rp9u/about_data

I cleaned and visualized this data from Jan 01, 2015 - Dec 31, 2024 to be able to see larger trends over time.
